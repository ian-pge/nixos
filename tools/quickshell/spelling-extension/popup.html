Alt+Tab corrige avec GPT (OpenAI). Ctrl+Alt+Tab utilise Qwen sur ce PC.

Ctrl+Alt+Maj+Tab restaure l’original.

Dans la prévisualisation : Entrée applique la correction, Échap ferme en gardant l’original.

Le panneau IA de Quickshell affiche les corrections en rouge et explique les fautes. Aucun message n’est envoyé à ta place. Avec GPT, le texte choisi est transmis à OpenAI.

Fonctionne dans les champs web classiques. Les pages internes de Chrome et certains éditeurs spéciaux ne sont pas pris en charge.
